# 🛰️ Question Space 백엔드 설정 가이드

이 앱의 질문/답변 데이터는 **내 Google 스프레드시트**에 저장됩니다.
아래 순서대로 따라 하면 완전히 비어 있는 **나만의 새 데이터 저장소**가 만들어집니다.

---

## 1. 구글 스프레드시트 만들기

1. [Google Sheets](https://sheets.google.com) 에서 새 스프레드시트를 만듭니다.
2. 이름은 자유롭게 (예: `Question Space Data`).
   - 시트(탭)는 비워 두어도 됩니다. 백엔드가 처음 실행될 때
     `Questions`, `Comments` 시트를 자동으로 생성합니다.

## 2. Apps Script 붙여넣기

1. 스프레드시트 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 엽니다.
2. 기본으로 열린 `Code.gs` 의 내용을 모두 지우고,
   이 폴더의 [`Code.gs`](./Code.gs) 내용을 그대로 붙여넣습니다.
3. 저장(💾)합니다.

## 3. 웹앱으로 배포

1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포** 를 클릭합니다.
2. 톱니바퀴 ⚙️ → **웹 앱** 을 선택합니다.
3. 설정:
   - **실행 계정(Execute as)**: `나(내 계정)`
   - **액세스 권한(Who has access)**: `모든 사용자(Anyone)`
4. **배포** 를 누르고, 처음이라면 권한 승인을 진행합니다.
5. 생성된 **웹 앱 URL**(`https://script.google.com/macros/s/..../exec`)을 복사합니다.

## 4. 관리자 비밀번호 설정 (스크립트 속성)

관리자 비밀번호는 **코드가 아니라 서버(스크립트 속성)** 에 저장합니다.
이렇게 하면 비밀번호가 깃 저장소에도, 빌드된 자바스크립트에도 들어가지 않습니다.

1. Apps Script 편집기 왼쪽 **프로젝트 설정(⚙️)** 을 엽니다.
2. 아래쪽 **스크립트 속성** → **스크립트 속성 추가** 를 클릭합니다.
3. 속성 이름 `ADMIN_PASSWORD`, 값에 원하는 비밀번호를 입력하고 저장합니다.

> 비밀번호를 바꾸려면 이 값만 수정하면 됩니다. 재배포는 필요 없습니다.

## 5. 프론트엔드에 연결

프로젝트 루트에 `.env` 파일을 만들고 복사한 URL을 넣습니다.

```env
VITE_API_URL=https://script.google.com/macros/s/여기에_내_URL/exec
```

`.env.example` 파일을 복사해서 시작하면 편합니다:

```sh
cp .env.example .env
# 그런 다음 .env 안의 URL 을 내 배포 URL 로 바꿉니다
```

저장 후 개발 서버를 재시작하면(`npm run dev`) 이제 모든 질문/답변이
**내 구글 시트**에 저장됩니다. 처음에는 데이터가 비어 있습니다. 🎉

## 데이터 구조

백엔드가 자동으로 만드는 두 개의 시트:

**Questions**

| id | author | text | topics | createdAt | ownerToken |
|----|--------|------|--------|-----------|------------|

- `topics` 는 쉼표로 구분된 카테고리 값입니다. (예: `imagination,dream`)
- `ownerToken` 은 작성자 본인 확인용 비밀 값입니다. 조회 응답에는 절대
  포함되지 않으며, 수정/삭제 권한 검증에만 쓰입니다. **수동으로 건드리지 마세요.**

**Comments**

| id | questionId | author | text | createdAt | ownerToken |
|----|-----------|--------|------|-----------|------------|

## 권한(삭제/수정) 검증 방식

삭제·수정은 **서버(Apps Script)에서** 다음 두 경우에만 허용됩니다.

1. **작성자 본인** — 질문/답변을 만들 때 서버가 발급한 `ownerToken` 을
   요청에 함께 보내고, 시트에 저장된 값과 일치할 때.
   (토큰은 작성한 브라우저의 localStorage 에 보관됩니다.)
2. **관리자** — 요청에 담긴 비밀번호가 스크립트 속성 `ADMIN_PASSWORD` 와 일치할 때.

둘 다 아니면 서버가 `{"error":"unauthorized"}` 를 돌려주고 아무 것도 바꾸지 않습니다.
즉, API 주소를 알더라도 토큰이나 비밀번호 없이는 남의 글을 지우거나 고칠 수 없습니다.

---

## 코드를 수정한 경우 재배포

`Code.gs` 를 수정했다면 **배포 → 배포 관리 → ✏️(연필) → 버전: 새 버전 → 배포**
순서로 다시 배포해야 변경 사항이 반영됩니다. URL 은 그대로 유지됩니다.

## 관리자 비밀번호

위 **4단계** 에서 설정한 스크립트 속성 `ADMIN_PASSWORD` 가 관리자 비밀번호입니다.
관리자 페이지에서 비밀번호를 입력하면, 그 값을 서버로 보내 **서버가 직접 검증** 합니다.
비밀번호는 코드·저장소·빌드 결과물 어디에도 들어가지 않습니다.

- 비밀번호 변경: 스크립트 속성 `ADMIN_PASSWORD` 값만 수정하면 즉시 반영됩니다.
- 관리자는 질문 삭제/수정뿐 아니라, 토큰이 없어도 모든 글을 관리할 수 있습니다.
